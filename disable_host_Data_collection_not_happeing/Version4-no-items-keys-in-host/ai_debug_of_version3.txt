4️⃣ What “not collecting data” really means in Zabbix

A host is NOT collecting data if ANY of these is true:

Case A — Item has no data at all
len(history) == 0

Case B — Item is stale (last value too old)
now - lastclock > allowed_interval

Case C — Partial data (far less than expected)
len(history) < expected_threshold


⚠️ You are currently only checking equality, which is meaningless here.

6️⃣ A CORRECTED version of filter_empty_history_hosts()
✅ Safe + realistic logic
def filter_empty_history_hosts(non_golive_hosts):
    hosts_not_collecting = []

    for host in non_golive_hosts:
        items = host.get('items', [])
        failed_items = []

        for item in items:
            history = item.get('allhistory') or []
            key = item.get('key_')

            if key == 'system.uptime':
                expected = system_uptime_standard_last_hour_value
            elif key == 'agent.ping':
                expected = agent_ping_standard_last_hour_value
            elif key == 'system.localtime':
                expected = system_localtime_standard_last_hour_value
            else:
                continue

            # Condition: no data or too little data
            if len(history) == 0 or len(history) < expected * 0.5:
                failed_items.append({
                    'key_': key,
                    'history_count': len(history),
                    'expected': expected
                })

        # If ALL keys are bad → host is not collecting
        if len(failed_items) == 3:
            hosts_not_collecting.append({
                'hostid': host.get('hostid'),
                'host': host.get('host'),
                'failed_items': failed_items
            })

    return hosts_not_collecting
